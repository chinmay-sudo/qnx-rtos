# QNX RTOS

Hands-on learning and development with **QNX Neutrino RTOS** using C.

## Scope

- Inter-process Communication (IPC)
- Processes and threads
- Synchronization and scheduling
- RTOS programming experiments


## Approach

Understand the concepts, implement the programs, verify their behavior, and document the results.

## Environment

- **IDE:** QNX Momentics
- **Execution:** QNX in VMware
- **Language:** C
- **Version control:** Git

## Repository Structure

Course exercises, independent practice, and engineering projects will be organized by topic as the repository develops.
